## Core Pipeline (6-Stage Lifecycle)

1. **`planned`** — Lock brand pack (`BRAND.md`, `DESIGN.md`, `COPY.md`, `brand-pack.json`), vector SVG mark, target domain route, and funnel archetype.
2. **`created`** — Generate canonical raw master plates (native image generation or Google Flow `Nano Banana 2.1` / `Veo 3.1` / `Omni 1.2 Flash` at `x1` batch count) inside an active BrowserOS Neo window (`type_at` + explicit submit). Record SHA-256 and credit delta (`hardCapCredits <= 2500`).
3. **`edited`** — Render deterministic WebP renditions (`1920w`, `1280w`, `640w`), programmatic typography overlays (`og-1200x630`, `square-1080`, `carousel-4x5`, `vertical-9x16` with `preserveFrame` for turnaround sheets), and `.mp4` `-poster.webp` frames via Sharp or `ffmpeg`.
4. **`qa_scored`** — Execute direct visual pixel inspection across 6 dimensions (max 30 points; minimum passing threshold `26/30`, zero garbled raster text or clipped character anatomy).
5. **`ready_for_publish`** — Emit `.vis.provenance.json` (`vis.provenance.v3`), content-addressed Cloudflare R2 `vis-media` upload plans (`masters/` + `renditions/`), Google Drive `04_APPROVED_MASTERS/<brand>/` paths, and interactive HTML5 Studio Cockpit.
6. **`placed`** — Wire verified R2 URLs, `<video poster>`, and static reduced-motion fallbacks into domain routes and confirm HTTP 200 live delivery.

## BrowserOS Neo Flow Automation Notes

- Operate inside the **active** Chrome window (`browseros-neo`); avoid creating inactive background windows for interactive Flow projects.
- Avoid full-page DOM `snapshot` on heavy Flow project views when modal iframes are mounted; pair `read` (`format: "text"`) with compact synchronous `evaluate_in_page` queries.
- Use `act` `kind: "type_at"` (real keyboard events) followed by `click_at` on `"Start generation"` rather than raw `.innerText` mutation so Angular/Slate composer state stays active.
- Always enforce explicit confirmation handling, `x1` batch count, and credit-ledger updates before launching subsequent shots.
