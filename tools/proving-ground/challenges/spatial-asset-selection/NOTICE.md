# NVIDIA USDCraft dataset notice

The catalog contains a modified selection of ten records from **USDCraft-10K**, published by NVIDIA. The dataset card identifies the dataset license as Apache License 2.0. A copy of that license accompanies this directory in [LICENSE-USDCraft.txt](LICENSE-USDCraft.txt).

[Dataset card at the pinned revision](https://huggingface.co/datasets/nvidia/USDCraft-10K/blob/6fbffb56c443237ddae9f6c7a05b72263fd1469e/README.md) · [Pinned manifest](https://huggingface.co/datasets/nvidia/USDCraft-10K/resolve/6fbffb56c443237ddae9f6c7a05b72263fd1469e/manifest.csv) · [USDCraft project and research credits](https://nvlabs.github.io/USDCraft/)

Starlight extracted the original object IDs, titles, category names, directory paths and publisher-supplied PhysX SHA-256 values. Starlight wrote the shorter English descriptions from those rows' published design prompts, selected the cases and authored the evaluation software. The text-based benchmark uses metadata. The optional browser case embeds two compressed renderings of the original classic desktop and long-arm stapler models, produced by Starlight from their visual meshes and source materials with new camera and lighting. Both source files were downloaded at the pinned revision and verified against their SHA-256 digests before rendering. The other eight geometry files were outside this exercise. [Source hashes, object IDs and rendering note](stapler-source-receipts.json). The standalone manifest SHA-256 is recorded in catalog.json.
